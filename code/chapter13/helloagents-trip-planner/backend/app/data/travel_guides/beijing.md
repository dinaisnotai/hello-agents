# 北京旅行决策知识库

本文件用于解释行程取舍，不用于替代地图、票价、营业状态、预约名额等实时数据。涉及开放安排和预约时，必须以官方渠道或实时工具结果为准。

## [历史文化][核心地标][预约] 故宫与天安门片区
- 适合历史文化首次到访用户；故宫通常应作为半日核心活动，避免与远郊景点混排。
- 故宫、国家博物馆、景山公园可作为相邻片区候选；若用户明确必去故宫，应优先保留故宫，再调整非必去景点。
- 热门场馆可能需要预约。RAG 只能提示“需核验预约”，不能承诺可进入。

## [历史文化][室内][雨天][预算] 国家博物馆与首都博物馆
- 博物馆适合作为雨天、高温、亲子和历史文化需求下的室内替代候选。
- 当预算紧张时，优先检查博物馆是否可替换收费的非必去历史类景点；实际票务与预约以实时信息为准。
- 将室内博物馆与附近的步行街区组合时，仍需由路线工具核验步行距离。

## [区域聚合][步行] 东城文化线路
- 故宫、景山、什刹海、南锣鼓巷属于市中心历史文化候选，适合按相邻区域拆分为一日或半日。
- 不要因为它们都属于历史文化就全部排进同一天；应根据实际路线、游览时长和每日步行上限分组。
- 老人、亲子或低步行需求下，优先保留一到两个核心点，并为中间交通和休息留出空间。

## [远郊][时间风险][交通] 长城类行程
- 长城类景点通常是高耗时活动，应单独安排半天或一天，并预留往返交通时间。
- 当每日时长或步行已超限时，优先跨天移动长城类景点，不应与市中心多个场馆硬拼在同一天。
- 选择具体长城段、交通方式和开放情况必须由地图与实时信息确认。

## [预算][免费替代] 预算紧张时的取舍
- 保留用户必去点；先替换或删除门票较高、优先级较低的非必去景点。
- 可优先考虑博物馆、公园、胡同和街区等低成本体验，以保持历史文化或城市漫步主题。
- 预算修复后必须重新计算交通与住宿成本，不能仅按景点门票判断。

## [住宿][地铁][预算] 住宿区域策略
- 预算有限时，可把住宿候选放在地铁可达区域，再由地图工具比较到每日核心片区的通勤成本。
- 不把“靠近所有景点”当作目标；多日行程应优先选择交通稳定、可覆盖主要区域的住宿位置。
- 酒店价格、房态和真实评价必须来自酒店或地图工具，不应由本地知识库提供具体承诺。

## [雨天][高温][亲子][老人] 天气与节奏修复
- 雨天或高温时，优先用博物馆等室内场馆替换非必去户外活动。
- 老人和亲子行程避免连续安排大面积户外步行；把一个核心景点和一个低强度活动组合更稳妥。
- 天气是否需要修复由实时天气 Agent 判断；本知识卡只提供替代方向。

## [餐饮][饮食限制] 餐饮信息边界
- “不吃海鲜”“少辣”“素食”等限制必须逐餐明确标注，未标注的餐饮候选不得视为满足。
- 本知识库不把泛化的“北京菜”描述当作饮食合规证明；点餐和过敏原须向商家二次确认。
