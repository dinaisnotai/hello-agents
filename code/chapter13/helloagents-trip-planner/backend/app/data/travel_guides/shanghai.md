# 上海旅行决策知识库

本文件用于解释行程取舍，不用于替代地图、票价、营业状态、预约名额等实时数据。涉及开放安排和预约时，必须以官方渠道或实时工具结果为准。

## [城市体验][区域聚合][夜景] 外滩、南京东路与豫园
- 南京东路、外滩、豫园属于相对集中的城市体验候选，可优先作为同日片区规划的起点。
- 外滩夜景更适合放在晚餐后或傍晚，避免把它当作需要白天长时间停留的主活动。
- 节假日和夜间人流会影响实际通行；路线与时间仍须由地图工具验证。

## [文化][室内][雨天][亲子] 上海博物馆与室内场馆
- 博物馆类场馆适合雨天、高温、亲子和文化偏好用户，能够替换部分非必去的户外活动。
- 替换时优先保持“文化”偏好，再检查与当日其他景点是否同片区。
- 展览、预约和开放安排变化较快，RAG 只提供策略，不承诺具体可进入。

## [城市漫步][步行][区域聚合] 武康路、安福路与徐家汇
- 武康路、安福路、徐家汇适合城市漫步主题，但连续步行距离可能较长。
- 不建议把这组景点与浦东地标混排在同一天；若步行超限，优先拆分到另一日或改用公共交通接驳。
- 具体顺序需由路线工具根据酒店位置重新计算。

## [浦东][交通][时间] 陆家嘴片区
- 陆家嘴可作为浦东城市地标体验的片区候选，与外滩隔江相望但不应仅凭视觉距离判断通行成本。
- 当日已安排豫园、南京东路等黄浦区活动时，是否加入浦东应由实际交通时间和节奏预算决定。
- 低步行或老人亲子需求下，应减少跨江切换次数。

## [预算][住宿][地铁] 预算紧张时的取舍
- 上海住宿和餐饮可能是主要成本项；预算修复先保留必去景点，再处理低优先级收费景点和住宿档位。
- 经济型住宿优先考虑地铁可达区域，并由地图工具验证到每天核心片区的通勤成本。
- 城市街区、博物馆和滨江步道可作为低成本体验方向；具体票价、房价和开放状态以实时数据为准。

## [雨天][高温][替代] 天气修复策略
- 雨天或高温时，优先把非必去户外漫步替换为室内文化场馆。
- 替换后的方案必须重新计算交通、步行和预约风险，不能只因“室内”就视为合格。
- 若用户必去户外夜景，应保留该硬约束，并调整其他可选活动。

## [餐饮][饮食限制] 餐饮信息边界
- “不吃海鲜”“少辣”“素食”等限制必须写入每顿餐的推荐描述；未明确标注即视为未验证。
- 地方菜或街区名称不能作为饮食合规证据；过敏原和具体菜品仍需向商家确认。
