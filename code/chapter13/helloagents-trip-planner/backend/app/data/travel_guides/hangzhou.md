# 杭州旅行决策知识库

本文件用于解释行程取舍，不用于替代地图、票价、营业状态、预约名额等实时数据。涉及开放安排和预约时，必须以官方渠道或实时工具结果为准。

## [自然风光][区域聚合][步行] 西湖片区
- 西湖周边适合按片区慢游，不适合在一天内频繁跨城移动。
- 断桥、苏堤、花港观鱼、雷峰塔等可作为西湖片区候选；实际顺序应由路线工具根据酒店位置和步行上限计算。
- 低步行、老人或亲子需求下，应减少环湖式连续步行，保留少量核心点并预留交通与休息。

## [自然风光][半日][交通] 灵隐寺与龙井村
- 灵隐寺、龙井村更适合作为半日线路候选，不宜与西湖另一端多个景点强行拼接。
- 当每日时长或步行超限时，优先跨天移动其中一组，而不是压缩游览时间到不可执行。
- 具体交通、预约和开放状态由地图与实时信息确认。

## [自然风光][独立安排][步行] 西溪湿地
- 西溪湿地适合独立安排半天，作为自然风光主题下的一个主要活动。
- 若同日已有西湖长距离步行或远郊活动，优先把西溪湿地移至其他天。
- 天气、游览方式和入口选择会影响步行量，应以路线结果为准。

## [雨天][室内][文化] 雨天替代方向
- 雨天时可将户外自然风光活动替换为博物馆、文化场馆等室内候选。
- 替换时应优先保持用户原有的文化或亲子偏好，再比较距离和预算。
- 不应仅因“室内”就认定可行，仍需检查预约、开放和交通。

## [节假日][拥堵][公共交通] 交通修复策略
- 节假日西湖周边可能拥挤；当步行或时间压力过高时，优先尝试公共交通而不是继续增加景点。
- 公共交通建议必须经路线 API 验证实际步行接驳，不能把整段公交距离误算为步行。
- 当交通切换仍不能满足每日步行限制，应减少景点或跨天移动。

## [预算][免费替代][城市漫步] 预算紧张时的取舍
- 预算有限时，优先保留用户明确必去的核心点，再减少门票较高、优先级较低的可选活动。
- 西湖片区的城市漫步和公共空间可作为低成本体验方向，但具体是否收费、是否开放以实时数据为准。
- 修复预算后需重新估算住宿、餐饮、交通和门票总额。

## [住宿][地铁][区域] 住宿区域策略
- 住宿候选应优先考虑到当日核心片区的可达性，不应只按直线距离或酒店名称判断。
- 若需降低住宿档位，保留交通可达性作为底线，并重新计算换酒店后的日间出行成本。
- 本知识库不提供具体酒店价格或房态。

## [餐饮][饮食限制] 餐饮信息边界
- 饮食限制需要在每顿餐的名称或描述中明确写出；没有标注时只能视为待确认。
- RAG 只能提醒“需明确标注”，不能证明餐厅实际能满足过敏原、素食或辣度需求。
