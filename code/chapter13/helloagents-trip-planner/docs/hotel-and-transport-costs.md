# 住宿与交通费用

预算为全团人民币规划估算，非成交价。出发日入住、结束日退房：三天两晚，一日游零晚；房价按房间和晚数，餐费及门票按人数。每天费用与预算合计使用同一套计算。

交通按实际路线段计价。步行免费；公共交通按人数预留每段票费；打车按车辆数（人数除以 VEHICLE_CAPACITY 向上取整）逐段计算起步价及里程费。混合出行短距离以公共交通为主，较长距离可打车，最终以路线段显示为准。

自有车辆计油电、通行费预留、每天停车费。租车增加按计费天数的租金和保险预留，在第一天集中列账。默认租赁计费天数等于行程天数，可按取还车时间折算后修改。押金不计消费。未包含取还车接驳、异地还车费、打车等待与夜间动态加价；城市间票价、停车和通行费需要另行确认。费率在 backend/.env 中配置，不是官方计价规则。各路段参考区间仅为估算浮动范围，不是统计置信区间。

酒店等级不再由用户偏好赋值。地图住宿分类不等于已核实星级，缺失评分不再填造 4.5 分。报价接通之前，酒店金额仍是每间每晚的规划预留；显示估算来源以及档次未确认提示。

## 酒店 API 准备

推荐 LiteAPI / Nuitée Connect。官方提供免费沙箱账户，可获取酒店内容和测试报价。免费沙箱不等于永久免费生产服务，也不能当作真实可订报价。中国目的地的覆盖、中文地名匹配和生产权限需用账户验证。

- 注册：https://dashboard.liteapi.travel/
- FAQ：https://docs.liteapi.travel/docs/faq
- 酒店列表及星级筛选：https://docs.liteapi.travel/reference/get_data-hotels
- 按日期、房间入住人数查询价格：https://docs.liteapi.travel/reference/post_hotels-rates

设置 HOTEL_API_PROVIDER=liteapi 并填写 LITEAPI_API_KEY 后，酒店查询会先调用酒店列表（按供应商星级筛选），再按入住日期、成人房间分配查询人民币全住期报价。沙箱金额标为测试报价，不可用于预订。供应商鉴权失败、无库存、币种不符时回退到地图估价并说明原因。金额按全部房间全住期累计，避免再次乘房间数、晚数；返回的额外税费计入金额。儿童入住、餐食、取消政策及未返回的费用需要在预订前确认。供应商地点通过地图地址查询获取路线坐标，不直接将供应商坐标当作高德坐标。密钥仅填 backend/.env，不填前端。适配器只查询，不执行预订。

## 景点与用餐

地图原始类型先排除医疗、餐饮、住宿、交通设施和未开放场所，景点经典资料只绑定明确别名，不再用“包含天坛/王府井”继承评分。午餐插入首个景点后，晚餐插入末个景点后；真实地图餐厅成为路线停靠点，未找到时保留待确认用餐时间。每餐预留60分钟，餐费仍是估算，营业与饮食限制未确认。均衡模式目的地内总预算10小时（含两餐及缓冲），明确指定的时间窗口优先。大型或远距离景点日允许少量景点，不按数量硬塞。

审查新增非法场所、餐厅确认状态、住宿档次、逐项偏好覆盖检查。安全问题阻断；未确认餐厅和酒店档次保留提示，不以补景点消除提示。偏好遗漏优先尝试合法补点或替换。修复接受规则比较各项数值超标幅度，同一约束逐步改善可提交，任何已有量化违规恶化仍回滚。
